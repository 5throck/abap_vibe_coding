## 1. Business Analysis

**Agent**: SD Analyst, LE Analyst
**Context file loaded**: `docs/sap-erp-module/sd-analyst.md`, `docs/sap-erp-module/le-analyst.md`

### AS-IS
현재 SAP 시스템의 주문 입력은 VA01, 출고(Delivery)는 VL01N 트랜잭션을 통해 개별적으로 처리됩니다. 사용자는 주문과 출고 프로세스를 유기적으로 연결하고, 진행 상태를 한눈에 파악하며 처리할 수 있는 통합 온라인 프로그램을 요구하고 있습니다.

### GAP
- VA01과 VL01N이 분리되어 있어 화면 전환 및 데이터 재입력의 번거로움이 있음.
- 주문 생성 후 즉시 출고 가능 여부를 판단하고 출고 문서를 생성하는 연계 프로세스가 부족함.
- 다량의 주문 건에 대한 출고 대기 상태를 가시적으로 확인하기 어려움.

### TO-BE Requirements
1. **주문/출고 통합 화면**: 단일 화면에서 주문 데이터를 입력하고, 저장 시 옵션에 따라 출고 문서(Delivery)까지 자동 생성.
2. **실시간 가용성 체크**: 주문 입력 단계에서 ATP(Available-to-Promise) 체크를 수행하여 출고 가능 수량 제시.
3. **상태 모니터링 Dashboard**: 입력된 주문의 진행 상태(주문완료, 출고대기, 출고완료)를 신호등 아이콘으로 표시.
4. **BAPI 연동**: `BAPI_SALESORDER_CREATEFROMDAT2`와 `BAPI_OUTB_DELIVERY_CREATE_SLS`를 연계 호출.

### Acceptance Criteria

- [ ] **AC-01**: 고객(KNA1) 및 자재(MARA) 정보가 유효한 경우에만 주문 입력 가능.
- [ ] **AC-02**: 주문 저장 성공 시 주문 번호(VBAK-VBELN)와 함께 생성된 출고 번호(LIKP-VBELN)를 즉시 표시.
- [ ] **AC-03**: 출고 수량은 주문 수량을 초과할 수 없으며, 가용 재고 범위 내에서만 자동 생성.
- [ ] **AC-04**: 처리 결과(성공/실패)를 ALV 로그 형태로 상세 출력.

**Handoff to Architect**: 주문 및 출고 BAPI 연계 로직 및 통합 UI 설계 필요.
