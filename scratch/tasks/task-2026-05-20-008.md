## 1. Problem Analysis

### AS-IS

ABAP SQL Quick Reference currently exists in:
- `agents/read-only-analyst.md` §ABAP SQL Quick Reference (full copy)
- Potentially referenced in module analyst files

The same rules are NOT present in:
- `agents/dba.md` (DBA also runs RunQuery)
- `agents/schema-inspector.md` (uses GetTable, but same risk)
- Module analyst skill files

### GAP

When DBA or a module analyst runs a query, they may use incorrect SQL syntax (DESC, LIMIT) because the canonical reference is buried in `read-only-analyst.md` only.

### TO-BE Requirements

1. Move the canonical ABAP SQL rules to `docs/context.md` under a new section "ABAP SQL Reference (All Agents)".
2. Replace the full copy in `agents/read-only-analyst.md` with a one-line reference: `> See docs/context.md § ABAP SQL Reference`.
3. Add the same one-line reference to `agents/dba.md` behavior rules.
4. Add to module analyst skill file template (for IMP-07).

### Acceptance Criteria

- [ ] **AC-01**: `docs/context.md` has a canonical "ABAP SQL Reference" section with all syntax rules.
- [ ] **AC-02**: `agents/read-only-analyst.md` references `docs/context.md` instead of duplicating the rules.
- [ ] **AC-03**: `agents/dba.md` references `docs/context.md` for SQL syntax.
- [ ] **AC-04**: No other file contains a standalone copy of the ABAP SQL rules without a reference pointer.
