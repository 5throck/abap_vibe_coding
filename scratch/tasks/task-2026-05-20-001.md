## 1. Problem Analysis

### AS-IS

`agents/form-expert.md` lists the following under `## Your Tools`:
- `browser_subagent`

`agents/gui-scripter.md` lists the following under `## Your Tools`:
- `browser_subagent`
- `vsp debug`
- `vsp health`

None of these tools exist in the vsp MCP server at `hyperfocused` mode.

### GAP

When form-expert or gui-scripter agents are dispatched and attempt to call `browser_subagent`, the call fails immediately. The agent halts or returns a tool-not-found error, disrupting the workflow.

`vsp debug` and `vsp health` in gui-scripter.md appear to be CLI commands, not MCP tools — their invocation method in the agent context is undefined.

### TO-BE Requirements

- Remove `browser_subagent` from both agent definitions.
- Replace with actual available tools or mark the capability as "requires manual step".
- Clarify `vsp debug` / `vsp health` CLI invocation in `gui-scripter.md` (document as Bash commands, not MCP tools).

### Acceptance Criteria

- [ ] **AC-01**: `agents/form-expert.md` contains no reference to `browser_subagent`.
