## 1. Problem Analysis

### AS-IS

Each of the 6 skill directories contains exactly one `SKILL.md` file. Content is unknown until read.

The `read-only-analyst` agent uses `context_file: agents/<module>-analyst.md` for domain knowledge, but these agent files focus on output format and governance, not query templates.

### GAP

Module-specific query templates and table quick references are embedded in individual agent files or exist only in developer memory. There is no reusable skill-level reference that `read-only-analyst` can load for consistent AS-IS analysis.

### TO-BE Requirements

For each of the 6 skills, populate `SKILL.md` with:
1. **Module Overview**: 2-3 sentence summary of the SAP module's core process
2. **Key Tables**: Top 10 tables with one-line descriptions
3. **Standard AS-IS Queries**: 3-5 reusable SQL templates for the most common analysis scenarios
4. **ABAP SQL Rules**: Reference to the central rule (DESCENDING, max_rows)
5. **Common Pitfalls**: Module-specific gotchas (e.g., client-dependent tables, document type filters)

### Acceptance Criteria

- [ ] **AC-01**: All 6 skill files contain a non-empty Module Overview section.
- [ ] **AC-02**: Each file lists at least 8 key tables with descriptions.
- [ ] **AC-03**: Each file contains at least 3 AS-IS query templates with commented purpose.
- [ ] **AC-04**: Each file references the central ABAP SQL syntax rule.
- [ ] **AC-05**: `docs/context.md` ABAP SQL rules section is updated to be the canonical reference for all skill files.
