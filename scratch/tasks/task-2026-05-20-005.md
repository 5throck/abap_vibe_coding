## 1. Problem Analysis

### AS-IS

`docs/context.md` documents the upstream vsp source build commands but does not record the version of the deployed `vsp.exe` binary in the project root (last modified: 2026-05-01).

`scripts/vsp-audit.ps1` has Check 1–5:
- Check 1: Script pairing (.ps1/.sh)
- Check 2: MCP prefix consistency (SAP_*)
- Check 3: Documentation sync
- Check 4: Memory index
- Check 5: MCP prefix in configs

No check for binary version or MCP connectivity.

### GAP

- Developers cannot determine if their `vsp.exe` is outdated.
- Audit script does not validate that the MCP server can actually start/connect.

1. Run `vsp.exe --version` and record the output in `docs/context.md`.
2. Add Check 6 to both audit scripts: invoke `vsp.exe --version` and report.
3. Optionally add Check 7: verify SAP connection health via `GetConnectionInfo`.
