# Celebrate Skill

이 스킬은 작업이 성공적으로 완료되었을 때 축하하는 도구입니다.

## Usage
`/celebrate [message]`

## Description
성공적인 코드 배포나 문제 해결 후 팀의 사기를 높이기 위해 사용합니다.

## Implementation
```bash
# Example output pattern
echo "🎉 Task Completed Successfully!"
echo "🚀 ABAP Objects Deployed and Activated."
echo "✨ Great job, Team!"
```
